## 🛠️ Tech Stack & Features
This portfolio is built using modern web development standards:
- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite 8](https://vite.dev/) (for fast and optimized builds)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (for modern geometric typography and layouts)
- **Deployment:** Fully automated using [GitHub Actions](https://github.com/features/actions) for CI/CD compilation and release
- **Hosting:** [GitHub Pages](https://pages.github.com/) (with SSL/HTTPS security)
- **Responsiveness:** 100% mobile-friendly, fluid layouts, and scroll-safe modern modals

## 📁 Project Structure
- `src/components/`: Modular React components (`Sidebar.jsx`, `About.jsx`, `Resume.jsx`, `Skills.jsx`, `CVModal.jsx`).
- `src/assets/`: Embedded static assets (profile picture, vectors).
- `.github/workflows/`: CI/CD automation script (`deploy.yml`) for automated builds.
